# phaseimpute QC Shiny App

Interactive quality control dashboard for visualizing phaseimpute pipeline results at Hendrix Genetics.

## Features

- **Overview Tab**: Pipeline metrics, parameters, and sample statistics
- **Quality & Accuracy Tab**: 
  - MAF-stratified imputation quality (with "show by sample" toggle)
  - Overall accuracy metrics (General Concordance, Non-Ref Concordance, Dosage r², Best GT r²)
  - Per-sample accuracy breakdown
- **Per-Chromosome Stats Tab**:
  - Per-chromosome summary table
  - SNP counts by chromosome (before/after imputation)
  - Accuracy by chromosome plot

## Usage

### On HPC

```bash
# Navigate to pipeline directory
cd phaseimpute

# Launch the app
bash shiny_qc_app/launch_app.sh
```

The app will start on port 3838. Access via browser at: `http://hpc-node:3838`

### Locally

```bash
# In R
shiny::runApp('app.R')
```

## Troubleshooting

### App stuck loading / not responding
If the app gets stuck on loading:
- **VS Code Remote SSH**: Delete the port 3838 in the Ports panel and re-add it
- **General**: Check if another process is using port 3838 (`lsof -i :3838`)
- Kill any stale R processes and restart the app

### R module issues on HPC
If you get library loading errors (e.g., `libicuuc.so` not found):
- The launch script runs `module purge` before loading R to avoid conflicts
- If issues persist, manually load the correct R module: `module load 2024 R/4.4.2-gfbf-2024a`

## Data Requirements

The app expects a phaseimpute pipeline output directory with:

- `multiqc/multiqc_data/multiqc_data.json` - MultiQC aggregated data
- `multiqc/multiqc_data/multiqc_glimpse_err_spl.txt` - GLIMPSE accuracy per sample
- `multiqc/multiqc_data/glimpse-err-grp-plot_*.txt` - MAF-stratified accuracy
- `qc_stats/summary_stats.txt` - Sample/SNP counts (generated by module)
- `qc_stats/per_chromosome_stats.csv` - Per-chromosome metrics (generated by module)
- `pipeline_info/params*.json` - Pipeline parameters

## Technical Details

- **Framework**: R Shiny with custom layout (migrated from shinydashboard)
- **Dependencies**: shiny, shinydashboard, DT, plotly, jsonlite, dplyr, tidyr, RColorBrewer
- **Styling**: Custom CSS with Hendrix Genetics brand colors (Navy #16315b, Green #9cbe2b, Light Blue #2091ae)
- **Data Source**: Primarily MultiQC outputs with pipeline-specific QC metrics
